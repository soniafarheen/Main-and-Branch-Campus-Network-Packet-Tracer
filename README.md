#🚀 Main-and-Branch-Campus-Network-Packet-Tracer

## 📌 Project Title
Design and Simulation of Albion University Campus Network using Cisco Packet Tracer


---

## 🔧 Key Configurations

- VLANs for 10 departments  
- Inter-VLAN Routing (Router-on-a-Stick)  
- Router-based DHCP Server  
- RIPv2 Dynamic Routing Protocol  
- Internal Web Server & External Email Server  
- Serial Links with Clock Rate  

---

## 📡 Network Overview

- 🏫 Main Campus  
  - 3 Buildings  
  - 8 Departments  

- 🏫 Branch Campus  
  - 1 Faculty  
  - 2 Departments  

- ☁️ Cloud Router  
  - External Email Server
